# has_scoreboard_visible <Badge type="info" text="libreforge" />

> 需要 TAB 计分板显示给玩家。

## 基本信息

| 属性 | 值 |
|------|-----|
| 类型 ID | `has_scoreboard_visible` |
| 所属模块 | libreforge |
| 分类 | 玩家状态（Player State） |

::: tip 反向参数
每个条件都支持可选的 `inverse` 参数，用于取反条件。
:::

## 配置示例

```yaml
- id: has_scoreboard_visible
```

# victim_as_player <Badge type="info" text="libreforge" />

> Set the player to be the victim - useful to give the victim items, etc. Only works when the victim is a player.

## 基本信息

| 属性 | 值 |
|------|-----|
| 类型 ID | `victim_as_player` |
| 所属模块 | libreforge |
| 分类 | 目标/玩家（Victim/Player） |

## 配置示例

```yaml
- id: victim_as_player
```

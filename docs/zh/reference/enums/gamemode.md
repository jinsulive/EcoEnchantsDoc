# GameMode 枚举

> 来源：Paper API · 4 个取值

> 用途：用于游戏模式条件（如 `in_gamemode`）。

| 值 | 含义 | 作用/说明 |
|----|------|-----------|
| `CREATIVE` | 创造模式 | 可飞行、无限方块 |
| `SURVIVAL` | 生存模式 | 标准生存玩法 |
| `ADVENTURE` | 冒险模式 | 受方块交互限制 |
| `SPECTATOR` | 旁观模式 | 仅可旁观，无法交互 |

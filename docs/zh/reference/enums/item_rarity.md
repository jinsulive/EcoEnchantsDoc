# ItemRarity 枚举

> 来源：Paper API · 4 个取值

> 用途：用于物品稀有度参数（如 `item_rarity`）。

| 值 | 含义 | 作用/说明 |
|----|------|-----------|
| `COMMON` | 常见 | 白色名称的普通物品 |
| `UNCOMMON` | 少见 | 黄色名称的少见物品 |
| `RARE` | 稀有 | 青色名称的稀有物品 |
| `EPIC` | 史诗 | 品红色名称的史诗物品 |
